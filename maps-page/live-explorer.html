The interactive maps are produced by running the Jupyter notebook locally. Once you do that, upload the resulting maps/ folder to the GitHub repo and the maps will appear here.

  1. Open Single_BHE_Analysis_GEE_CMIP6_Folium.ipynb on your machine
  2. Run all cells (this may take 15–30 min)
  3. The notebook now ends with cells that auto-export 24 HTML files to a maps/ folder
  4. Upload the contents to your GitHub repo at maps-page/individual/ and maps-page/ensemble/
  5. Refresh this page — your map will load
