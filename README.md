# 🚀 Portfolio Site v6 — Real notebook maps via iframe

## 🎯 Why this version is different

In v5, the live map tried to **simulate** your notebook's analysis in JavaScript. That was a mistake — your model uses scipy, FLS heat-transport equations, and Brent's iterative root-finding. None of that runs in a browser.

**This version takes a smarter approach:** the notebook generates the real folium HTML maps once, and the website embeds them via iframe based on the dropdown selection.

**Benefit:** what visitors see is the **authentic thesis output** — the 6 togglable layers, both color legends, Germany boundary — exactly like cells 36 and 37/38 of your notebook.

---

## 📋 Two-step deployment

### Step 1: Generate the maps (run once)

Open `files/Single_BHE_Analysis_GEE_CMIP6_Folium.ipynb` on your machine. I added 5 new cells at the end that:

1. Create a `maps/` folder structure
2. Loop through all 8 models × 2 scenarios → save 16 individual HTML files
3. Compute the ensemble (Mean, P25, P50, P75) for both scenarios → save 8 ensemble HTML files

**Total: 24 HTML files in `maps/individual/` and `maps/ensemble/`**

⚠️ **Before running the new export cells**, make sure you've already executed the model for ALL 8 models × 2 scenarios above (cells 5-35). Each of these `*_ssp245` and `*_ssp585` variables must exist in memory.

⏱️ **Time estimate:** ~5–10 minutes for the export cells (the heavy modeling was already done in earlier cells).

### Step 2: Upload everything

After running the notebook, your local folder should look like:

```
your-folder/
├── Single_BHE_Analysis_GEE_CMIP6_Folium.ipynb
├── BBC_ssp245_2000_2100_Germany_mean.tif (and other TIFFs)
└── maps/                        ← NEW! Generated by the notebook
    ├── individual/
    │   ├── BBC_ssp245.html
    │   ├── BBC_ssp585.html
    │   ├── CanESM_ssp245.html
    │   └── ... (16 files total)
    └── ensemble/
        ├── ssp245_mean.html
        ├── ssp245_p25.html
        ├── ssp245_p50.html
        ├── ssp245_p75.html
        ├── ssp585_mean.html
        └── ... (8 files total)
```

**Upload to GitHub:**
1. Inside your `VaibhavJ97.github.io` repo, navigate to the `maps-page/` folder
2. Click into the `individual/` folder → upload all 16 `*_ssp*.html` files
3. Click into the `ensemble/` folder → upload all 8 `ssp*_*.html` files
4. Commit changes

## 🚀 Deployment Steps

### Phase A: Update the website code (the easy part — do this first)

1. Go to https://github.com/VaibhavJ97/VaibhavJ97.github.io
2. Delete: old `index.html`, `files/`, `maps-page/`, `thesis/`, `assets/` (KEEP the `data/` folder!)
3. Upload everything from this `portfolio-v6` folder
4. Commit

5. Visit your site — homepage and thesis page work immediately.
6. Click "Maps" → click "Open the explorer" → you'll see an empty-state screen explaining the next step (because the maps aren't generated yet)

### Phase B: Generate and upload the maps

1. Download the updated notebook from this zip: `files/Single_BHE_Analysis_GEE_CMIP6_Folium.ipynb`
2. Make sure your TIFF files are alongside the notebook locally
3. Run all cells (the new export cells are at the end)
4. Locate the generated `maps/` folder
5. Upload `maps/individual/*.html` and `maps/ensemble/*.html` to GitHub at the matching paths in `maps-page/`
6. Refresh your live explorer page → maps now load
